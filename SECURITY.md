# Security policy

## Supported versions

Security fixes are provided for the latest GitHub release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/lofi-town/lofi-town-anki/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected add-on and Anki versions, operating system, reproduction
steps, and expected impact. Remove account details, authorization codes, card
content, and other private data from screenshots and logs.
